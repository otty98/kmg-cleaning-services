Kamgabaza Cleaning Services — Booking System
A lightweight, browser-based booking app for a cleaning services business. Built with plain HTML, CSS, and JavaScript — no frameworks, no backend, no fuss.

What It Does
Customers can visit the page, pick a service, choose a date and time slot, and submit a booking — all without leaving their browser. Bookings are saved locally so they persist between page refreshes, and the whole thing runs by simply opening a single HTML file.

Features

Service booking form — name, service type, date, and 2-hour time slot
Conflict prevention — won't allow two bookings on the same date and time
Date & time validation — blocks past dates and time slots that have already passed today
Live booking dashboard — all bookings render dynamically on the page
Delete functionality — remove any booking with one click
Inline notifications — success and error feedback without any browser popups


AI Assistance
AI tools were used during development to help debug the booking validation logic, tighten up code structure, and think through edge cases (like blocking time slots that had already passed on the current day). All decisions, testing, and final implementation were done manually.

How to Run

Clone or download the repository
Open index.html in any browser
Book a service

No installs. No build step. Just open and go.
